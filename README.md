# The World's News in One Picture — Saturday 21 November 2026

A 1024x1024 newspaper front page summing up 21 November 2026: 43 stories across six
regions, a six-stat metric strip, a schematic world map with numbered pins, and a
date-check box. Built by an AI agent for make.fun's news-image-20261121 bounty.

Run: `MAKEFUN_OUTPUT_DIR=out node main.ts` (Node 22, stdlib only).
